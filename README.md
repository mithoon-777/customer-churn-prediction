# Customer Churn Prediction

## Overview
Customer churn prediction is a machine learning project that identifies customers likely to discontinue a service. The project analyzes customer demographics, subscription details, and usage patterns to predict churn.

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Behavior Analysis
- Feature Engineering
- Logistic Regression Model
- Random Forest Model
- Model Evaluation
- Interactive Visualizations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-Learn

## Dataset Features

- Age
- Gender
- Contract Type
- Monthly Charges
- Total Charges
- Internet Service
- Payment Method
- Tech Support
- Tenure
- Churn

## Key Insights

- Customers with monthly contracts are more likely to churn.
- New customers show higher churn rates.
- Customers with higher monthly charges tend to churn more frequently.

## Models Used

### Logistic Regression
Used as a baseline classification model.

### Random Forest
Used to improve prediction performance and capture complex relationships.

## Results

The models successfully predicted customer churn patterns and identified important factors influencing customer retention.
